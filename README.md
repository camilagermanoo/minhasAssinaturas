# 💳 Minhas Assinaturas

> Gerencie seus gastos recorrentes em um só lugar.

---

## 🚀 Sobre o projeto

O **Minhas Assinaturas** é uma aplicação web desenvolvida para ajudar usuários a organizar e acompanhar suas assinaturas mensais e anuais.

A ideia é centralizar serviços como Netflix, Spotify, etc., permitindo um melhor controle financeiro.

---

## ✨ Funcionalidades

- ✅ Cadastro de usuário  
- ✅ Login  
- ✅ Navegação entre páginas  
- ✅ Dashboard inicial  
- ✅ Componentes reutilizáveis  
- 🔜 Adicionar assinaturas  
- 🔜 Listar assinaturas  
- 🔜 Controle de gastos  

---

## 🛠 Tecnologias

- ⚛️ React  
- ⚡ Vite
